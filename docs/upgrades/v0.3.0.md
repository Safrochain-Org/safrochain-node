# Upgrade guide: v0.3.0

The step-by-step guide for validators and node operators (timeline, vote,
build or download, cosmovisor, checks) is on the documentation site:

**<https://docs.safrochain.com/governance/mainnet-upgrade-v0.3.0>**

| | Mainnet |
|---|---|
| Chain ID | `safrochain-1` |
| Current binary | `v0.2.2` |
| New binary | `v0.3.0` |
| Upgrade plan name | `v0.3.0` (cosmovisor directory `upgrades/v0.3.0`) |
| Go toolchain | 1.26.11 |
| Store changes | none |
| State-machine breaking | **yes**: every node must switch at the upgrade height |

Do **not** run `v0.3.0` before the upgrade height, and do **not** keep running
`v0.2.2` after it: in both cases the node computes a different app hash and
stops.

## Build from source

```bash
git clone https://github.com/Safrochain-Org/safrochain-node.git
cd safrochain-node
git checkout v0.3.0
make install                      # Go 1.26.11 (fetched automatically by Go >= 1.21)
safrochaind version --long | grep -E '^(version|commit|go):'
safrochaind query wasm libwasmvm-version   # 2.2.10
```

## Release binaries

Statically linked `linux/amd64` and `linux/arm64` binaries and `SHA256SUMS`
are attached to the GitHub release `v0.3.0`.

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

## After the upgrade

```bash
safrochaind q upgrade applied v0.3.0
safrochaind q consensus params            # block.max_gas = 100000000
```

The testnet (`safro-testnet-1`) upgrade is announced separately.
